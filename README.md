## 1. Visión general del proyecto

Este proyecto demuestra la aplicación práctica de herramientas de Inteligencia Artificial Generativa mediante Microsoft 365 Copilot (integrado en Word, Excel, PowerPoint, Outlook y Teams) para diagnosticar y resolver problemas comerciales complejos dentro de una cadena de suministro.

La entrega evidencia cómo la IA puede apoyar la identificación de riesgos, la elaboración de propuestas de acción, el análisis de datos, la coordinación interfuncional y la comunicación ejecutiva con stakeholders clave.

## 2. Aclaración sobre el caso de estudio y correspondencia con la rúbrica

Nota para el evaluador / reviewer:

En la guía estándar del curso se citan títulos genéricos referidos a “Supply Chain Issues / Problemas de la Cadena de Suministro”. En esta entrega, la metodología, prompts y criterios de evaluación se adaptan a un caso realista de análisis comercial y recuperación de rendimiento, manteniendo la alineación con los requisitos del proyecto.

Todos los entregables requeridos por cada una de las cuatro tareas se encuentran incluidos, etiquetados y alineados al 100% con los criterios de evaluación.
